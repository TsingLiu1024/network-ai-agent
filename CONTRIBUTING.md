\# Contributing Guide





Thank you for contributing to Network AI Agent.







\## Development Setup





Clone repository:





```bash

git clone https://github.com/TsingLiu1024/network-ai-agent.git

```





Install dependencies:





```bash

pip install -r requirements.txt

```







\## Branch Naming





Use:





```

feature/xxx



fix/xxx



docs/xxx



```







Example:





```

feature/add-deepseek-provider

```







\## Commit Convention





Follow:





```

feat:

fix:

docs:

refactor:

test:

```







Example:





```

feat: add DeepSeek LLM provider

```







\## Pull Request





Before submitting:





\- Run tests

\- Format code

\- Update documentation







Thank you ❤️
